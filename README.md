## ✨ DisplayU

DisplayU는 대학생의 전시와 작품을 발견하고, 기록하고, 소통할 수 있는 전시 플랫폼입니다.

- 전시·작품·작가 정보 제공
- 후기·질문·감상 및 라운지 커뮤니티
- 전시·작품·작가 아카이브
- Google·Kakao OAuth 로그인과 이미지 업로드
